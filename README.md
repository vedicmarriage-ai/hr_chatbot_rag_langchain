# HR chatbot

Local retrieval over HR and policy documents, with the answer generated by Sarvam through the VedicMarriage AI service.

Retrieval uses Chroma, hybrid BM25 + dense search, and a cross-encoder rerank. If that retrieval returns no text, the bot refuses and does not call a model. If the AI chat service times out or returns 503, generation falls back to local `qwen2.5:1.5b`.

Details: [`docs/SARVAM_GENERATION.md`](docs/SARVAM_GENERATION.md). Version: [`CHANGELOG.md`](CHANGELOG.md).

## Run

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
set -a && source .env && set +a
.venv/bin/uvicorn main:app --host 127.0.0.1 --port 8010
```

`AI_CHAT_BASE_URL` points at the AI service (`http://127.0.0.1:8091` on this host). `AI_SERVICE_TOKEN` matches that service. The Sarvam key is not stored here.

Ollama must be running for the default embedding model `qwen3-embedding:0.6b`. Pull `qwen2.5:1.5b` only for fallback.

## Ask

```bash
curl -sS -X POST http://127.0.0.1:8010/api/ask \
  -H 'Content-Type: application/json' \
  -d '{"question":"Is registration free?"}'
```

`/health` returns the version. `/chat` accepts `message` and an optional `session_id`.

Production widget path: [`docs/PRODUCTION.md`](docs/PRODUCTION.md) (`/hr-chat` on nginx, not a public `:8010`).
